# Ingeniería de Sistemas · Universidad de la Amazonia

Página de divulgación del programa, creada exclusivamente con HTML5 y CSS3. No usa JavaScript, frameworks, paquetes ni procesos de compilación.

**Sitio publicado:** https://uniamazonia-sistemas.vercel.app/

**Repositorio público:** https://github.com/luiszsanchez/uniamazonia-sistemas

Publicado en Vercel el 3 de octubre de 2026. El acceso público se comprobó mediante una solicitud sin autenticación (HTTP 200). La publicación inicial se hizo mediante Vercel Drop. El repositorio público contiene el código y los recursos visuales. Para publicar futuras actualizaciones automáticamente se puede conectar este repositorio en la configuración Git del proyecto de Vercel.

## Abrir la página

Abre `index.html` en cualquier navegador moderno. Todos los recursos visuales están incluidos en `assets/`; la página funciona sin instalar nada. Se requiere conexión para visitar los documentos y portales externos.

## Funcionalidad

- Navegación por secciones mediante anclas.
- Menú móvil nativo con `details` y `summary`.
- Preguntas frecuentes desplegables, también con HTML nativo.
- Enlaces al plan de estudios, registro calificado, brochure y repositorios oficiales.
- Admisiones, teléfono (`tel:`), correo (`mailto:`) y ubicación en Google Maps.
- Diseño adaptable, foco visible para teclado, enlace para saltar al contenido y respeto por la preferencia de movimiento reducido.

Los enlaces externos se abren en otra pestaña. Los enlaces de correo y teléfono dependen de las aplicaciones configuradas en el dispositivo. No se incluyen formularios que simulen inscripciones: los trámites se realizan en el portal institucional.

## Publicar en GitHub y Vercel

1. Crea un repositorio **público** llamado `uniamazonia-sistemas` en GitHub.
2. Carga los archivos de esta carpeta en la raíz del repositorio. Conserva la carpeta `assets` y su estructura. `index.html` debe quedar en la raíz.
3. En Vercel elige **Add New → Project** e importa ese repositorio.
4. Selecciona **Framework Preset: Other**, **Root Directory: .**, sin comando de compilación. El directorio de salida es la raíz (`.`). No hay dependencias que instalar.
5. Pulsa **Deploy** y copia la dirección de producción. Comprueba que puede abrirse sin iniciar sesión.
6. Verifica la URL del repositorio en una ventana privada: debe mostrar el código sin autenticación.

Documentación de Vercel: https://vercel.com/docs/builds/configure-a-build
